# 09. ACCOUNTING — Traceability

Baseline (`BL`) applies. **Sole posting path**: `Accounting\Services\JournalPostingService::post()` — used by manual journals AND all source-document posting rules. Invariant: Σdebits = Σcredits asserted (BCMath) before insert + checksum stored + fiscal-period row locked. Posted entries are immutable: corrections via reversal/credit-debit notes only (Spec §48-I). Manual account-code conditionals in controllers are forbidden (Spec §48-G); account resolution comes from `posting_rules` + COA.

Shared services: `Accounting\Actions\{CreateAccount, UpdateAccount, CreateManualJournal, PostReversal, ScheduleRecurringJournal, PostOpeningBalance, CloseFiscalYear, TransferRetainedEarnings, RecordReceipt, RecordPayment, WriteOffBadDebt, RunDepreciation, DisposeAsset, PostBudget, ConvertCurrency}` · `Accounting\Services\{JournalPostingService, LedgerService, AgingService, TrialBalanceService, FinancialStatementService, TaxService, PeriodCloseService, BudgetService, AssetService}` · `Reporting\FinancialReports`.
