# 13. REPORTS — Traceability

Baseline (`BL`) applies. Spec §34: **server-side report services** (not SQL fragments in controllers); every report supports date range, branch scope, user/role scope, product/customer/supplier filters, payment method, status, export, print, PDF, pagination, totals/subtotals, saved filters, scheduled generation. **Totals are never fabricated** — every displayed figure traces to a DB calculation. Report implementations are shared with the per-module report rows (02-114…, 03-68…, 04-63…, etc.); this module provides the unified Reports hub, cross-domain custom builder, and scheduling.

Shared: `Reporting\ReportRegistry` (DB `report_definitions`), `Reporting\ReportRunService` (queue, snapshot, export), `Reporting\Exporters\{CsvExporter, XlsxExporter, PdfExporter}`, `SavedFilterService`, `ScheduledReportService` (cron → generate → store → notify via outbox).
