# 04. INVENTORY — Traceability

Baseline (`BL`) applies. Core rule: **stock truth = immutable `stock_movements`**; `stock_balances` is derived and rebuildable; valuation layers per configured method (FIFO / LIFO / Weighted Average / Standard); FEFO for expiry goods; negative-stock guarded by row lock + CHECK where disabled.

Shared services: `Inventory\Actions\{CreateProduct, DuplicateProduct, CreateOpeningStock, PostStockAdjustment, CreateStockTransfer, DispatchTransfer, ReceiveTransfer, RecordDiscrepancy, PostCycleCount, RecordDamage, RecordLoss, RequestWriteOff, PostWriteOff, ConsumePackaging, GenerateBarcodeLabel, CreateReorderSuggestion}` · `Inventory\Services\{StockLedgerService, ReservationService, ValuationService(FIFO/LIFO/WAC/Standard), FefoAllocator, SerialService, BatchService, ReorderCalculator, ReconciliationService}` · `Inventory\Queries\{StockQuery, ValuationQuery, MovementQuery, ExpiryQuery}` · engines: Workflow, Accounting (`posting_rules` for write-off/adjustment/valuation), Documents, Audit, Intelligence.
