# 11. MARKETING — Traceability

Baseline (`BL`) applies. Spec §21: marketing = real systems with reusable contacts, segments, templates, scheduling, **delivery states**, opt-out state, reports. External platforms = clean adapters + config screen; core CRM/marketing works without them. **Never fake delivery/open/click numbers** — only provider-verified events (webhook) or locally tracked application events.

Shared services: `Marketing\Actions\{CreateCampaign, ScheduleCampaign, SendCampaign, ExpandSegment, RecordOptOut, CreateLead, UpdateLeadStage, ScoreLead, ConvertLead, CreateAffiliate, CreateInfluencerCampaign, RecordSocialIntegration}` · `Marketing\Services\{SegmentResolver, CampaignDispatcher, AttributionService, LeadScorer, OptOutService}` · `Marketing\Adapters\{SmsChannelPort, EmailChannelPort, WhatsAppChannelPort, PushPort, FacebookPixelPort, GoogleAdsPort, TikTokPixelPort, Ga4Port}` (all optional; truthful `not_configured`) · Notification outbox shared for delivery; Audit; Intelligence (campaign cost/revenue, lead response-time analytics with explainability).
