# 15. SETTINGS — Traceability

Baseline (`BL`) applies. Settings engine (Spec §38): structured DB records — key, group, value, type, scope (global/company/branch), effective date, translated help text, **secret flag + encrypted storage** for credentials, full audit history. **Unsafe "everything configurable" switches forbidden**: authorization, isolation, FK integrity, debit/credit balance, decimal arithmetic, posted-record immutability, idempotency, numbering uniqueness, token entropy, password hashing, transport security are **not** toggleable (tested in 15 row S-23).

Shared: `Settings\SettingsService` (typed get/set with cache invalidation after commit), `Settings\Controllers\*`, `Security\SecurityPolicyService`, `Backup\BackupService`, `Maintenance\MaintenanceService`, `Documents\TemplateController`, `Api\ApiKeyService`, `IntegrationService`.
